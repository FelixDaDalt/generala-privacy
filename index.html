Política de Privacidad - Anotador de Generala

Última actualización: Mayo 2026

Anotador de Generala es una aplicación diseñada para registrar y calcular puntajes de partidas de Generala y/o proveer de dados virtuales para jugar.

Datos recopilados

La aplicación no solicita registro de usuario ni recopila directamente información personal como nombre, correo electrónico o número de teléfono.

Almacenamiento local

La aplicación puede guardar datos de partidas y configuraciones únicamente en el dispositivo del usuario para su correcto funcionamiento.

Publicidad

La aplicación utiliza Google AdMob para mostrar anuncios. Google AdMob puede recopilar ciertos datos del dispositivo, identificadores, información de uso y datos relacionados con publicidad para mostrar, medir y mejorar los anuncios.

El tratamiento de dichos datos se realiza conforme a las políticas de privacidad de Google: https://policies.google.com/privacy

Menores de edad

La aplicación está orientada a público general. No recopilamos intencionalmente información personal de menores de edad.

Compartición de datos

La aplicación no vende ni comparte información personal directamente con terceros. No obstante, los servicios de publicidad integrados pueden procesar datos según sus propias políticas.

Cambios en esta política

Esta política puede actualizarse ocasionalmente. Cualquier cambio será publicado en esta misma página.
